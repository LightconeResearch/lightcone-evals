# Union2.1 data provenance

`SCPUnion2.1_mu_vs_z.txt` is the Supernova Cosmology Project Union2.1
magnitude-versus-redshift table, downloaded from:

<https://supernova.lbl.gov/Union/figures/SCPUnion2.1_mu_vs_z.txt>

The project describes the columns and compilation at
<https://supernova.lbl.gov/union/>. The bundled table contains the 580 Type Ia
supernovae that pass the compilation's usability cuts. Confirm redistribution
terms with the data owners before contributing this task outside Lightcone's
benchmark repository.
