# Union2.1 data provenance

Downloaded from the Supernova Cosmology Project's Union2.1 compilation page,
<https://supernova.lbl.gov/Union/figures/>:

- `SCPUnion2.1_mu_vs_z.txt` — magnitude-versus-redshift table for the 580 Type
  Ia supernovae passing the compilation's usability cuts. Header carries the
  SALT2 nuisance parameters and the calibrated absolute magnitude `M(h=0.7)`
  for both the statistical-only and with-systematics error treatments.
- `SCPUnion2.1_covmat_nosys.txt` — 580x580 statistical-only covariance matrix.
  Its diagonal matches the error column in the mu_vs_z table exactly.
- `SCPUnion2.1_covmat_sys.txt` — 580x580 covariance matrix including
  systematics.

The project describes the columns and compilation at
<https://supernova.lbl.gov/union/>. Confirm redistribution terms with the data
owners before contributing this task outside Lightcone's benchmark repository.
